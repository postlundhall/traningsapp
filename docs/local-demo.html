Lokal snabbstart av webbapplikation

Krav: Java 21 eller nyare

(Maven krävs ej)

  1. Öppna Terminal (Mac/Linux) eller PowerShell (Windows) och klona repot: 
    git clone https://github.com/postlundhall/traningsapp.git
cd traningsapp
  2. Välj startmetod:
    Alternativ 1: Direkt körning 
    ./mvnw spring-boot:run
    Alternativ 2: Bygg JAR och kör 
    ./mvnw clean package
java -jar target/traningsapp.jar
    ⚠️ Om ./mvnw inte körs: Kör först chmod +x mvnw
  3. Åtkomst:

    🌐 Webbappen:
    http://localhost:8080

    🗄️ Databaskonsol (medan app körs):
    http://localhost:8080/h2-console/
    Användarnamn: sa · Inget lösenord

    💾 Data sparas i ./data/
